# Phase 3 run files

One file per slice, `docs/runs/phase3/<slug>.md`, kept as [the Phase 2 run files](../phase2/readme.md) are: the brief, the builder's report, the review and the integration notes, on the slice's branch while it runs and on `main` once it merges. The design is [`docs/03-roadmap-appendix/phase3.md`](../../03-roadmap-appendix/phase3.md); where each slice stands is in [STATUS](../../10-status.md).

Each run file is on its slice's branch until the slice merges.
