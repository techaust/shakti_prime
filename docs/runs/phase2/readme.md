# Phase 2 run files

One file per slice, `docs/runs/phase2/<slug>.md`, kept as [the Phase 1 run files](../phase1/readme.md) are: the brief, the builder's report, the review and the integration notes, on the slice's branch while it runs and on `main` once it merges. The design is [`docs/03-roadmap-appendix/phase2.md`](../../03-roadmap-appendix/phase2.md); where each slice stands is in [STATUS](../../10-status.md); the steps from a brief to `main` are in [slice-integration](../../runbooks/slice-integration.md).
